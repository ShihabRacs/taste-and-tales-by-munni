How do I get a token?
  1. Open GitHub → New fine-grained token.
  2. Expiration: pick a date (e.g. 1 year).
  3. Repository access: Only select repositories, then choose this site's repository.
  4. Permissions: Contents: Read and write and Commit statuses: Read-only.
  5. Generate, copy, and paste it above. Never share it.
